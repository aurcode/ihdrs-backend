### 1.2 项目背景

#### 1.2.1 项目概述

**项目名称：** 智能手写数字识别系统（Intelligent Handwritten Digit Recognition System, IHDRS）

**开发单位：** 留学生第一组

**项目背景：**

随着人工智能技术的快速发展，手写数字识别在教育、金融、邮政、物流等领域有着广泛的应用需求。本项目旨在开发一个基于深度学习的手写数字识别系统，通过卷积神经网络（CNN）等模型来实现高精度的数字识别功能。

系统采用前后端分离的微服务架构，支持PC端Web管理和移动端（Android/iOS）应用，通过异构系统集成实现Java业务逻辑与Python深度学习模型的协同工作。

#### 1.2.2 系统组成

| 子系统名称 | 主要功能                     | 目标用户       |
| ---------- | ---------------------------- | -------------- |
| 后端服务   | 业务逻辑处理、数据持久化     | 系统服务       |
| 模型服务   | 深度学习模型训练与推理       | 系统服务       |
| 管理端     | 系统管理、模型管理、数据分析 | 管理员、分析师 |
| 用户端     | 手写识别、历史查询、反馈提交 | 普通用户       |

## 2.任务概述

### 2.1 系统目标

本系统的主要目标是构建一个高准确率、易使用、可扩展的智能手写数字识别平台。

#### 2.1.1 主要目标

| 目标编号 | 目标描述                           | 优先级 | 验收标准                    |
| -------- | ---------------------------------- | ------ | --------------------------- |
| G-001    | 实现高准确率的手写数字识别         | P0     | MNIST测试集准确率≥98%       |
| G-002    | 支持实时手写识别和图片上传识别     | P0     | 识别响应时间≤500ms          |
| G-003    | 提供完整的深度学习模型训练管理功能 | P0     | 支持至少5种模型类型         |
| G-004    | 支持多模型管理和动态切换           | P0     | 模型切换时间≤1秒            |
| G-005    | 实现跨平台用户端支持               | P0     | 支持Android 8.0+和iOS 13.0+ |

#### 2.1.2 次要目标

| 目标编号 | 目标描述                           | 优先级 | 验收标准                |

| G-007    | 实现用户错误反馈和模型持续优化机制 | P1     | 反馈处理闭环完整        |

### 4.2 用户端功能需求

#### 4.2.1 用户认证功能（P0）

**FR-U001 用户注册**

| 属性     | 描述                                                         |
| -------- | ------------------------------------------------------------ |
| 功能标识 | FR-U001                                                      |
| 功能名称 | 用户注册                                                     |
| 优先级   | P0（核心功能）                                               |
| 前置条件 | 用户未登录                                                   |
| 输入     | 用户名（3-50字符）、密码（6-20字符）、邮箱（可选）、手机号（可选） |
| 处理逻辑 | 1.验证用户名唯一性<br>2.验证密码强度<br>3.密码BCrypt加密<br>4.创建用户记录 |
| 输出     | 注册成功确认、用户ID                                         |
| 后置条件 | 用户账户创建成功，状态为ACTIVE                               |
| 异常处理 | 用户名已存在返回错误码1001；密码强度不足返回错误码1002       |

**FR-U002 用户登录**

| 属性     | 描述                                                         |
| -------- | ------------------------------------------------------------ |
| 功能标识 | FR-U002                                                      |
| 功能名称 | 用户登录                                                     |
| 优先级   | P0（核心功能）                                               |
| 前置条件 | 用户已注册且状态为ACTIVE                                     |
| 输入     | 用户名、密码                                                 |
| 处理逻辑 | 1.验证用户名存在<br>2.验证密码正确<br>3.生成JWT Token<br>4.更新登录信息 |
| 输出     | JWT Token、Token类型、过期时间、用户信息                     |
| 后置条件 | 用户登录次数+1，更新最后登录时间                             |
| 异常处理 | 用户名或密码错误返回错误码401；用户被禁用返回错误码403       |

**FR-U003 Token验证**

| 属性     | 描述                                                        |
| -------- | ----------------------------------------------------------- |
| 功能标识 | FR-U003                                                     |
| 功能名称 | Token验证                                                   |
| 优先级   | P0（核心功能）                                              |
| 前置条件 | 用户持有Token                                               |
| 输入     | Authorization Header（Bearer Token）                        |
| 处理逻辑 | 1.解析Token<br>2.验证签名<br>3.验证有效期<br>4.获取用户信息 |
| 输出     | Token有效性、用户信息                                       |
| 后置条件 | 无                                                          |
| 异常处理 | Token无效或过期返回错误码401                                |

| 输出     | 识别数字（0-9）、置信度（0-1）、概率分布、处理时间           |
| 后置条件 | 识别记录保存至数据库                                         |
