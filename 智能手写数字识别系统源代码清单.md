### 文件统计汇总

| 子系统                 | 主要技术           | 说明                                  |
| ---------------------- | ------------------ | ------------------------------------- |
| **Java后端**           | Spring Boot 3.5.6  | 控制器、服务、实体、DTO、Repository等 |
| **Vue管理端**          | Vue 3 + Vite       | 页面组件、API、状态管理、工具类等     |
| **React Native移动端** | React Native       | 页面、组件、服务模块                  |
| **Python模型服务**     | Flask + TensorFlow | API、模型定义、服务、工具             |
| **文档**               | Markdown           | 需求、概要设计、详细设计、测试计划    |
| **配置文件**           | YAML/JSON/XML      | Docker、Maven、npm等配置              |
